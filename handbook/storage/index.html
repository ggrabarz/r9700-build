    Storage & streaming¶

    VRAM is compute, host RAM is the expert arena, NVMe is capacity. The tiers are not interchangeable, and the most common build mistake is buying the storage tier as if it were the bandwidth tier.

    1. The three tiers¶

    Tier Holds Bandwidth Role
    VRAM (128 GB on 4 cards) dense weights + hot experts + KV 640 GB/s per card, 2.56 TB/s on four all decode compute
    DDR4/DDR5 (128–512 GB) cold expert arena, pinned; PCIe staging 170.6 GB/s on the proven 8-ch DDR4-2666; 307–410 GB/s on 8-ch DDR5 the CPU pool + staging
    NVMe (1–8 drives) checkpoint, cold experts, PLE table 7 GB/s per Gen4 drive; 14.9 GB/s per Gen5 x4; 119.2 GB/s for eight capacity and warm-up only

    Why NVMe is not the bandwidth tier: eight Gen5 x4 drives at 14.9 GB/s each is 119.2 GB/s — less than a third of 409.6 GB/s of DDR5-6400, and barely two-thirds of the proven box's 170.6 GB/s DDR4.

    Worse, streaming through a host staging buffer costs 2× DRAM traffic (NVMe→DRAM write, then DRAM→VRAM read). Eight Gen5 drives therefore need 224 GB/s of DRAM traffic = 55 % of a 409.6 GB/s budget. Above roughly 12 Gen5 drives the DRAM bus, not the flash, becomes the wall.

    2. The proven box needs one drive¶

    The reference machine runs one Samsung 990 PRO 1 TB at $254.39 — 2.37 % of the machine — as the whole-disk OS install (/boot/efi + / ext4, no LVM, no RAID). It holds a 27.78 GB FP8 checkpoint that is 100 % VRAM-resident, and steady-state decode touches 0 bytes of it.

    Option Cost Verdict
    1 × Samsung 990 PRO 1 TB (proven) $254.39 right answer for a dense model that fits in VRAM
    8 × Samsung PM1743 15.36 TB ~$35,280 3.29× the entire proven machine, 1.10× the whole 12-card fleet. Only coherent with 512 GB DDR5: 8 drives at the 0.5× derate need 224 GB/s naive (131 % of 170.6 — fails) or 112 GB/s zero-copy (86 % — fits)
    8 × SN850X 4 TB $5,520 32 TB; fine as a multi-checkpoint archive, still bandwidth-poor

    Model-store cost is effectively zero: 931 GiB usable against a 27.78 GB checkpoint is 2.98 % used, and the marginal cost of another model copy is $0 because it lives in page cache. PLP and endurance matter only for artefacts you cannot re-download.

    The corollary that explains the whole reference build: a single 990 PRO caps a DeepSeek-class MoE at 0.9–3.7 tok/s (against 40–79 tok/s on a proper array). That is why the reference fleet serves a dense 27 B. The storage tier is not a budget line; it is the decision that determines which model class the machine can serve at all.

    3. When you do need an array: size it correctly¶

    3.1 The 8 × 256 GB RAID0 is dead¶

    • 256 GB drives have 2–4 NAND packages at ~2–3.5 GB/s each; eight of them ≈ 16–28 GB/s — the same as two 2 TB Gen5 drives, at 4× the lanes and 4× the failure domains.
    • DeepSeek packs are 239–274 GB, so 2 TB is already thin.
    • Buy 2 × 2 TB (or 1 × 4 TB) Gen5, striped. That is the Strata recommendation.

    3.2 Size the RAM tier to the expert arena¶

    Strata's own model page states the rule: the model fits when RAM ≥ experts + ~10 GB, and a bigger GPU does not lower the RAM needed.

    RAM Consequence on Qwen3.8-Flash-Next
    128 GB ceiling is UD-Q5_K_XL. Q6_K_XL (118 GB) and Q8_0 (136 GB) fall into --mmap-experts low-RAM mode
    256 GB the packs run resident; no disk streaming during decode

    In the measured low-RAM case, one box spent 82 % of every token waiting on the host stream; it went from 36 → 79 tok/s only once experts were resident.

    The jump from 256 GB to 512 GB DDR5 is +$14,800 at October 2026 street prices — more than the entire GPU pool at MSRP. Do not buy it unless the expert arena actually needs it.

    3.3 The PLE / n-gram / Engram table¶

    This is the single most important storage decision for Flash-Next and GLM-class models.

    Placement Effect
    NVMe + 8 GB RAM cache (B45) 5.2–6.3 k prefill
    Host RAM (3-card box, 256 K fp8) 5–7 k → 24 k prefill (3–4×), 150–220 tok/s decode
    ~51 GB reserved (B26) 102.2 → 437.8 tok/s c1→c8
    47.7 GiB pinned (B14) the 236 → 1,192 tok/s monolith

    Keep the table in RAM if it fits. If it must live on SSD, give it its own drive — it is read randomly and stays hot — and keep that drive on CPU lanes. A chipset x16 slot has no PCIe atomics and RCCL fails there.

    4. Layer-split placement, if you stream¶

    The algorithm that works (A8 §1.2), now a MoE-only contingency rather than the box recipe:

    • Dense model: unit = one transformer block + its input_layernorm / post_attention_layernorm; separate units for model.embed_tokens, model.norm, lm_head.
    • MoE model: unit = (block i, expert group g) where g is a contiguous slice of that block's routed-expert list. An expert's w1/w2/w3 triple lives on exactly one device so it can be DMA'd atomically.
    • The shared expert, router and attention of block i stay co-located with the first expert group of block i, so the always-hot part of a block is one contiguous read.
    • Never split a single tensor across SSDs.
    • Overlap: read ahead into pinned host buffers with io_uring / O_DIRECT, then hipMemcpyAsync on a dedicated stream with an hipEvent dependency on the compute stream.
    • Prefer the pinned-RAM tier over NVMe whenever the expert fits in RAM. That converts an NVMe read into a DRAM read and keeps the PCIe link free.

    The residency break-even: a layer-split DeepSeek V4.1 Flash needs ≥34.2 % of the routable active-expert bytes in VRAM for 20 tok/s. On the proven single-drive tier the same target needs ≥91.8 % — unreachable. That number, not the model size, sizes the expert cache.

    5. Lane budget and storage¶

    On a 128-lane single socket the board exposes 7 × PCIe 5.0 x16 + 1 × x8 + 2 × NVMe x4 = exactly 128 lanes, with no PCIe switch in the GPU tree. So:

    • You get 8 GPUs and 2 NVMe at full width on a switchless board.
    • Every further NVMe is bought by demoting a GPU link.
    • The storage tier — not the GPU tier — is what needs a switch.
    • On the proven quad, 4 × x16 = 64 lanes leaves room; the M.2 slot must still be CPU-direct.

    Measured link reality: the cards run PCIe 4.0 x16, 28.4 GB/s, not Gen5's 63 GB/s. Puget independently measured 27.6 GB/s P2P on the same part. H2D with pinned buffers is ~50–55 GB/s; that is the ceiling for any weight streaming.

    PCIe has a floor and it is x1. Four R9700 layer-split at Gen3 x1 drop to 316 tok/s prefill / 50 decode on a 27 B, against 5,187 / 118 at Gen4 x16 — a 16× prefill loss. x4–x8 is tolerable; one lane is not.

    6. Storage answer in one paragraph¶

    For the proven dense build, buy one 1 TB NVMe and nothing else. For Strata / Flash-Next, buy 256 GB of RAM and 2 × 2 TB (or 1 × 4 TB) Gen5, put the PLE table in host RAM, and stream experts only for the part that does not fit. Never buy eight small drives in RAID0, never buy enterprise 15.36 TB drives for a box that serves a 28 GB checkpoint, and never treat NVMe bandwidth as a substitute for host RAM.
