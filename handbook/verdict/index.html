    Verdict¶

    The best 4× R9700 inference platform is the proven EPYC 7452 quad, with two engines at TP=2 and Qwen3.8-27B FP8. If the box must run Strata and large MoE models, upgrade RAM to 256 GB and the checkpoint store to one 4 TB Gen5 drive. If single-stream latency and aggregate throughput matter more than $/token, build the Threadripper PRO Radiance TP4 monolith instead.

    This page is the decision, not the evidence. Each number is tagged and sourced in the chapter that owns it.

    Recommendation 1 — the default: the proven EPYC 7452 quad ($10,733.91)¶

    Build it if you want the lowest-risk 4-card box and you care about cost per token.

    Part Choice
    GPUs 4 × ASRock Radeon AI PRO R9700 Creator 32 GB (gfx1201), 210 W cap each
    CPU AMD EPYC 7452 (Rome, 32C/64T, 128 PCIe 4.0 lanes, 8-channel DDR4) — $127 used
    Board ASRock Rack ROMED8-2T/BCM (AST2600 BMC)
    RAM 8 × 16 GB DDR4-2666 RDIMM = 128 GB (170.6 GB/s)
    Storage one Samsung 990 PRO 1 TB NVMe
    PSU / case / cooling SilverStone HELA 2050R, SilverStone RM44 4U, ARCTIC Freezer 4U-M + 2 × NF-A8
    Software vLLM-Radiance (Radiance patches on ROCm), 2 engines × TP=2, Qwen3.8-27B FP8 + FP8 KV + MTP

    Why it wins: it is the only 4-card build with published, end-to-end measured throughput and cost on this exact silicon.

    • 493 written tok/s across 12 cards / 3 identical nodes, i.e. 41.1 tok/s per GPU on real jobs (MEASURED — guide p.8).
    • 623 tok/s aggregate at 16 users, 837 W for one 4-card box (MEASURED — guide p.81).
    • $18.15 per million output tokens on real jobs; break-even vs GPT-5.6 Sol at 3.4 h/week (DERIVED — docs/ARCHITECTURE.md §7).
    • The quad deliberately sidesteps the 128-lane wall that makes an 8-card single-socket build awkward; the 64-lane-class Rome platform is enough because the cards run Gen4 x16 in practice.

    The one change to make: if the workload is Strata / large-MoE expert streaming, buy 8 × 32 GB = 256 GB instead of 8 × 16 GB, and one 4 TB Gen5 NVMe instead of the 1 TB. That is Recommendation 3, and it is the difference between "runs" and "runs without streaming from disk".

    Recommendation 2 — the throughput ceiling: Radiance TP4 monolith on Threadripper PRO¶

    Build it if single-stream latency and maximum aggregate tok/s matter more than $/token.

    Part Choice
    GPUs 4 × R9700, 211 W cap, all four on CPU-direct PCIe 5.0 x16, P2P between every pair
    CPU / board Threadripper PRO 9955WX + ASRock WRX90 WS EVO (or equivalent WRX90)
    RAM 122–128 GB DDR5
    Storage 1–2 TB Gen5 NVMe
    Software Radiance (standalone C++/HIP) TP4 with ar_oneshot_4rank + --tp-wire exact; Qwen3.8-Flash-Next

    Measured result (MEASURED — r/LocalLLM 1xe1u1i, LlamaPerf report):

    • 236 tok/s single stream, 371 @2, 591 @4, 890 @8, 1,192 tok/s @16 concurrent; 11.27 ms/step.
    • That is roughly 3× the same box on llama.cpp + speculative decode (65–75 tok/s), and ~45 % ahead of 2 × TP2.
    • A second, independent Gen4 box (EPYC 7R13, 256 GB DDR4-3200) reproduces ~7.8–8.2k prefill and 170–244 tok/s TG from 100k to 250k context with tuned flags (MEASURED — B18).

    Minimum viable recipe (all verified):

    • NCCL_PROTO=Simple for any RCCL path — the gfx1201 tuning-index bug deadlocks TP ≥ 2 otherwise.
    • GPU_MAX_HW_QUEUES=1 — fixes the gfx1201 slow-dispatch state (seen on 6/8 boots; 139 → 210 tok/s).
    • BIOS ACS disabled for real P2P (19.7 vs 11.6 GB/s busbw); each KFD node must list 3 p2p_links.
    • --tp-wire exact is the safe default: wht6 at 4 ranks is a tiered int8 + Hadamard wire, not 6-bit, and it is lossy above 128 KiB messages for ~2 % prefill.
    • Cap power at 210–211 W. Capping 4 cards to 210 W doubled gpt-oss-120b TP4 decode (44.6 → 89.4 tok/s) in one measured build; amdgpu.ras_enable=0 doubled another (40 → 97 tok/s). Neither is a thermal effect.

    Cost: roughly $18k–$25k depending on TR Pro SKU, DDR5 and PSU. You are paying ~2× Recommendation 1 for ~2–3× the peak throughput; the $/token is worse, the latency is better.

    Recommendation 3 — the Strata build (what the large-MoE stack actually needs)¶

    Build it if the box will run Strata + Qwen3.8-Flash-Next / DeepSeek V4.1-Flash.

    Part Do not buy Buy instead Why
    RAM 8 × 16 GB (128 GB) 8 × 32 GB (256 GB) Strata's own model page: the model fits when RAM ≥ experts + ~10 GB; a bigger GPU does not lower the RAM needed. At 128 GB the ceiling is UD-Q5_K_XL; Q6_K_XL (118 GB) and Q8_0 (136 GB) fall into --mmap-experts low-RAM mode, where one measured box spent 82 % of every token waiting on the host stream (36 → 79 tok/s only once experts were resident).
    SSD 8 × 256 GB NVMe in RAID0 2 × 2 TB (or 1 × 4 TB) Gen5, striped 256 GB drives have 2–4 NAND packages (~2–3.5 GB/s each); eight ≈ 16–28 GB/s — the same as two 2 TB Gen5 drives, at 4× the lanes and 4× the failure domains. DeepSeek packs are 239–274 GB, so 2 TB is thin.
    Everything else — keep the 4 × R9700 + Threadripper PRO Strata lists "four R9700 cards (Linux)" as tested hardware for DeepSeek V4.1-Flash.

    Critical software fact: Strata does layer split + expert streaming, not tensor parallel — there is no --tp 4. And Qwen3.8-Flash-Next has only 2 KV heads, so clean TP sharding tops out at TP=2; vLLM uses expert parallel for it. That is why the Strata box wants capacity and host bandwidth, not a TP4 all-reduce.

    Keep the n-gram table on its own drive (it is read randomly and stays on SSD), and keep M.2 on CPU lanes — a chipset x16 slot has no PCIe atomics and RCCL fails there.

    What every session agreed on — the non-negotiables¶

    Rule Evidence
    4 cards is the sweet spot; 6 is wrong. TP works at 2/4/8; 1,200 W of GPU already sits near a 120 V branch limit. r/LocalLLaMA 1pkrnpo; r9700-4x-builds.md B20
    Use vLLM-Radiance / Radiance, not stock vLLM. Stock on the same dual-card box: 15.88 → 156.21 tok/s; Radiance 32.00 → 198.78; +MTP 62.75 → 320.23. Puget; docs/ARCHITECTURE.md §4
    TP=2 per engine × 2 engines for dense 27B; TP=4 only for MoE. 27B FP8 + 262K KV does not fit one 32 GB card. guide p.149; ARCHITECTURE §4
    210 W cap, set at every boot. It reverts after a cold power-off. guide p.114
    NCCL_PROTO=Simple on any RCCL path; otherwise TP≥2 deadlocks. Level1Techs 250504; ROCm/rccl PR #2166
    CPU-direct lanes only. Chipset slots break RCCL/TP. PCIe 4.0 x16 ≈ 28.4 GB/s in practice, not Gen5's 63. Puget; michal-koniu notes
    One NVMe checkpoint store is enough for the proven build. A multi-SSD array only makes sense for Strata expert streaming, and then as 2–4 large drives, not 8 small ones. guide; thread 321464d6
    Do not mix vendors in one TP group. Adding an RTX 4500 Ada lost throughput on every model tested; an R9700 alone beat R9700 + 7800 XT. r/LocalLLaMA 1xhq12y, 1xcpbqd
    Validate any AITER-linear run. Forcing it at TP≥2 with per-rank K not a multiple of 1024 emits NaN. vllm#28649 (xy7ra)
    Bare metal, not KVM/VFIO. ncclCommInitRank hangs under passthrough even with full 27.6 GB/s P2P; bare metal initialises in 0.12 s. ARCHITECTURE §9
    IOMMU stays in translated mode. iommu=pt causes silent P2P corruption on gfx1201 — peer reads return 0xFF, writes are dropped. A8 §2; verified on the box

    What not to build¶

    • 8 GPUs on one 128-lane socket — the lane wall is real; the quad avoids it. Going 4 → 8 added only ~14 % throughput in the one measured upgrade (c1 173.5 → c8 510.2).
    • gpt-oss-120B in BF16 — 0.2 tok/s at TP4; it needs MXFP4/Quark.
    • DeepSeek V4.1-Flash's 510 GB FP8 checkpoint through vLLM cpu_offload — not viable. The Strata ISTA packs (239–274 GB, 46–64 GB RAM) are the viable route and are the ones actually tested on four R9700s.
    • 6 cards — TP works at 2/4/8, and non-power-of-two counts can refuse to load entirely.
    • 8 × 16 GB with Strata — falls into low-RAM mode.
    • 8 × 256 GB RAID0 — same bandwidth as two large drives, 4× the lanes and failure domains.
    • Stock fan curves — they follow the CPU and pause the run at the 68 °C card-area warning.
    • --enforce-eager — it roughly halves decode.

    One-line answer¶

    Buy Recommendation 1 — the $10,733.91 EPYC 7452 quad, 4 × R9700 at 210 W, 128 GB DDR4-2666, one 1 TB NVMe, vLLM-Radiance at 2 × TP=2. It is the only measured $/token anchor on this part (623 tok/s @16 users, 837 W, $18.15/Mtok, 3.4 h/week break-even). Upgrade RAM to 256 GB and one 4 TB Gen5 drive if the box runs Strata. Choose the TR PRO 9955WX/WRX90 Radiance TP4 monolith only if 236 tok/s single-stream / 1,192 tok/s aggregate is worth roughly double the spend.
